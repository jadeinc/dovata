#
# What to read off it:
#
#   * `architecture qwen3moe` is the field that decides everything downstream. Note it
#     is not "Qwen3-Coder" — the arch vocabulary is a family name, and a later Qwen
#     release may well keep declaring qwen3moe.
#   * Every hyperparameter under `qwen3moe.` is namespaced by that same string. Change
#     the architecture and you change the key names the loader looks for.
#   * `context_length 262144` is what the weights were trained for; JADE_CTX_SIZE
#     defaults to 32768, far below it.
#   * `expert_count 128 / expert_used_count 8` is the 30B-total, ~3B-active MoE shape.
#   * The profile matched on `general.name`, which is free text. That is the soft spot.
